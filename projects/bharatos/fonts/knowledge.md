## 1. "Monospace vs Proportional" 
Monospace / Fixed-width →   each character takes the same space, great for terminals, code editors, and command lines.

![MyImage](@site/projects/bharatos/fonts/_assets/Proportional-vs-monospace-v5.svg)

## 2. "serif vs sens-serif" 


Serif → has the little decorative strokes ("feet"), better for print — books, newspapers, magazines.
The serifs help guide the eye across a printed page.    

Sans-serif → "sans" literally means without in French, so no decorative strokes. Better for screens — websites, apps, UIs. Cleaner and more legible at screen resolutions.


![MyImage](@site/projects/bharatos/fonts/_assets/serif_vs_sens-serif.png)
